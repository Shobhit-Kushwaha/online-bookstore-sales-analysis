# Online Bookstore Sales Analysis (SQL)

## Project Overview

This project analyzes online bookstore sales data using SQL to generate business insights. The goal is to understand sales performance, customer behavior, revenue trends, and book category performance using PostgreSQL.

## Tools & Technologies

- PostgreSQL
- SQL
- pgAdmin

## Dataset

The project contains three datasets:

- Books
- Customers
- Orders

## Project Structure

```
Online-Bookstore-Sales-Analysis

├── data
│   ├── books.csv
│   ├── customers.csv
│   └── orders.csv

└── sql
    ├── schema.sql
    ├── basic_queries.sql
    └── advanced_queries.sql
```

## SQL Concepts Used

- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- LAG()
- DENSE_RANK()
- Date Functions

## Analysis Performed

### Basic Analysis
- Total books sold by genre
- Average book price analysis
- Most frequently ordered books
- Customer order analysis

### Advanced Analysis
- Revenue contribution by genre
- Monthly revenue comparison
- Sales ranking using window functions
- Revenue trend analysis

## Key Objective

To transform raw bookstore sales data into meaningful insights using SQL and improve decision-making through data analysis.
